# SmartGarden 🌱

SmartGarden is a deterministic, adaptive smart irrigation and environment control system designed to run locally (Raspberry Pi–ready), remain explainable, and continuously improve through feedback-based calibration.

## Key Features
- Sensor monitoring (temperature, humidity, pressure, light, soil)
- Predictive irrigation with safety constraints
- Adaptive dosing via calibration feedback loop
- Full analytics dashboard (FastAPI + Chart.js)
- SQLite-based local storage
- Mock hardware for development

## Running Locally
1. Create venv
2. Install requirements
3. Run scheduler
4. Run FastAPI dashboard
